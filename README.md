<h1>notetaku</h1>
a fast, private, offline-first note-taking app for windows and macos.

all data is stored locally on your machine. notetaku makes zero network calls except for optional update checking (which only contacts GitHub). your notes never leave your computer.

## install

download the latest `.exe` or `.dmg` from [releases](https://github.com/KiMCHiSOFT/notetaku/releases).
